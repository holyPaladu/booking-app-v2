# 0001. Стек: Bun + Elysia + PostgreSQL

- Статус: принято
- Дата: 2026-06-24

## Контекст
Нужен лёгкий типобезопасный бэкенд для набора микросервисов с быстрым стартом.

## Решение
Рантайм **Bun**, HTTP-фреймворк **Elysia** (встроенная валидация `t`, OpenAPI, end-to-end типы, Eden), БД **PostgreSQL** через драйвер `postgres` (raw SQL, без ORM). Хеширование паролей — `Bun.password` (argon2id).

## Последствия
- (+) Минимум зависимостей, единый источник типов из схем валидации, встроенный argon2id.
- (−) Экосистема Bun/Elysia моложе Node; часть инфраструктуры (config, миграции) пишем сами.
