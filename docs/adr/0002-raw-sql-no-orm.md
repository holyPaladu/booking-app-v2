# 0002. Raw SQL без ORM

- Статус: принято
- Дата: 2026-06-24

## Контекст
Запросы относительно простые; важны контроль над SQL и предсказуемая производительность.

## Решение
Драйвер `postgres` с теговыми шаблонами (параметризованные запросы). Доступ к данным изолирован в `repo` за портом (`types/ports/*.port.ts`), так что слой данных подменяем в тестах.

## Последствия
- (+) Полный контроль над SQL, нет «магии» ORM, repo за портом легко мокать.
- (−) Имена колонок не проверяются компилятором против схемы — следить вручную (см. инцидент `email_verificated`).
- (−) Миграции и типы пишем руками.
